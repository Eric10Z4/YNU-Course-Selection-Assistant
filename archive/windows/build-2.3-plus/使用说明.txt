YNU 抢课助手 打包说明
====================

前提：电脑已安装 Python 3.10+（https://www.python.org/downloads/）
      安装时务必勾选 "Add Python to PATH"

打包步骤：
    1. 打开命令行（Win+R 输入 cmd 回车）
    2. cd 到本文件夹，例如：
       cd C:\Users\你的用户名\Desktop\release
    3. 执行：
       python build.py
    4. 等待几分钟，完成后成品在 dist\QiangKeWeb.exe

脚本会自动创建干净的虚拟环境（.build_venv），避免系统/conda
环境中的无关库被打进 exe 导致体积暴涨。首次打包需要联网安
装依赖，之后再打包会复用已有环境，速度更快。

文件清单：
    qiangke_web *.py   主程序源码（文件名含 qiangke_web 即可）
    build.py           打包脚本
    lite_ocr.py        轻量验证码识别模块
    ocr_model.onnx     验证码识别模型
    ocr_charset.json   字符集映射
    logo.png           程序图标
    background.jpg     界面背景图

注意事项：
    - 打包产物约 50 MB
    - 如需重新打包干净环境，删除 .build_venv 文件夹即可
    - 运行 exe 需要系统自带 WebView2 运行时（Win10/11 一般自带）
