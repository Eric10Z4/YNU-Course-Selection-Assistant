## 发布前修复

- 同一教学班 ID 的确认结果按有效批次区分，避免跳过其它批次或重复排队。
- 登录或核对耗时跨过计划允许窗口时，首次提交前再次检查，过期不发送。
- 排队启动保留前台服务；界面、通知停止和服务结束取消排队意图，停止后不能被旧启动请求覆盖。
- 退选通过原生控制队列准备并检查取消标记，排队或登录期间停止后不再提交。
- 公开 APK 禁止调试和合成测试模块，检查应用 ID、ABI、16 KB 对齐、来源提交和签名。
